# 검토 결과 작성 기준

검토일, 코드 기준(HEAD와 미커밋 변경 포함 여부), 기능과 제외 범위, 국가·차량·플랫폼·SDK·카테고리·주행 의도를 적는다. 자료가 없는 조건은 미확인으로 표시한다. 열람한 정책에는 URL, 절, 열람일, 본문/이미지 접근 상태를 남긴다.

전체 검토는 P01–P09와 D01을 각각 `문제 있음 / 관찰 범위 적합 / 검증 필요 / 적용 제외`로 표시하고 근거를 붙인다. 변경 검토는 영향받는 항목만 쓰고 전체 점검이 아님을 명시한다. 계획과 실제 구현을 구분한다.

## 발견별 필드

- ID·제목·우선순위: P0 즉시 대응할 안전·데이터 보호 문제, P1 핵심 기능/목표 출시를 막는 문제, P2 조건부 위험·권고·개선.
- 판단: `의무 위반 확인 / 기능 장애 확인 / 조건부 위험 / 권고 미반영 / 검증 필요`. 코드 사실과 정책 적용의 확신은 별개다.
- 정책: ID, 공식 직접 링크·절·확인일, 의무/권고/예시/플랫폼 동작 구분.
- 근거: 실제 `파일:행`, 함수, 화면 또는 기획 문구. 정적 사실과 실행 관찰을 구분.
- 발생 조건·영향: 어느 차량·상태·동작에서 무엇이 막히는지.
- 수정안: 변경 지점·구현 순서·대체 UX·실패/미지원 처리·의존성.
- 완료 조건: 재현 시나리오와 기대 결과. 불명확한 정책은 확인 질문과 공식 문의 대상만 적고 외부 연락은 전송하지 않는다.

심각도 순으로 정리하고 수정 순서, 미확인 조건, 수행/미수행 검증을 적는다.

## 관련 기능이 있을 때 선택할 검증

| 영역 | 시나리오와 기대 결과 |
| --- | --- |
| 주행 | 시작부터 제한 활성, 정차→주행, 작업 도중 제한 진입, 복귀 시 재평가. 금지된 작업이 계속되거나 콜백으로 다시 활성화되지 않음. 정차 앱은 플랫폼 차단 확인. |
| 지역 | 북미·유럽·그 외의 플랫폼 비트 조합과 제한값 반영. 앱 국가 분기로 제한을 덮어쓰지 않음. |
| 차량 API | 지원/미지원, 읽기 불가, area 없음, null, 일시 불가, 권한/연결 오류, 지연 콜백. 값 부재를 정상값으로 표시하지 않음. |
| 화면 | 1/2 window, portrait/landscape, 크기 변경, 시스템 패널/IME, 야간, 글자 확대. 핵심 정보·조작 유지. layout-land 유무만으로 판정하지 않음. |
| 생명주기 | 백그라운드·복귀·재생성·프로세스 종료·재연결. 불필요한 갱신 중단, 상태 복원, 오래된 응답 방지. |
| 개인정보 | 저장·로그·캐시·백업·URL·컴포넌트 경로. 민감정보 보호 및 계정 전환 시 세션 분리. |
| 성능 | 기기·빌드·측정 도구·구간을 기록하여 CPU/RAM 측정. 수치 없으면 검증 필요. |
| 통신 | 오프라인·저대역폭·재연결. 시간 제한·유한 재시도·신선도 표시·중복 방지. |
| 오디오 | 포커스 거부/상실/duck/반환, Gleo·통화·내비·긴급음, suspend/resume. 포커스 없이 재생하지 않음. |
