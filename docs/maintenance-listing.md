# 정비 목록과 사용자 등록 폼 (2026-11-12)

서버 `/maintenance/summary`는 검증된 제조사 기준(MANUFACTURER)을 먼저, 사용자 기준(USER)을 다음에 반환한다. 각 그룹은 위험(DANGER), 기한·거리 도래, 다음 예정일, 남은 거리, 항목명 순으로 정렬한다. 날짜와 거리를 임의 환산해 하나의 예상일로 만들지 않는다. 서버와 Android의 기존 2개 제한은 제거했다.

차량 정비 화면·홈·기본정보는 같은 정비 요약을 사용하며 제조사와 사용자 목록을 나눠 표시한다. 마지막 정비 날짜·거리가 모두 없는 항목은 오너에게 ‘첫 정비 기록 등록’을 제공한다. 사용자 항목이 없으면 새 사용자 정비 등록 버튼을 제공한다. 멤버와 미인증 사용자의 공용 목록 노출 및 오너만 수정하는 권한 검사는 유지한다.

등록 폼은 Material 윤곽선 입력칸, 항목/주기/마지막 정비 구역, 날짜 달력으로 구성한다. 주행 제한·화면 이탈 시 에디터와 달력을 함께 닫는다. 제조사 항목을 열면 이름·권장 주기는 읽기 전용으로 두고 기존 evidenceId와 MANUFACTURER basis를 보존한다. 사용자 등록은 USER로 저장한다. 검증되지 않은 제조사 문서를 새 제조사 근거로 생성하지 않는다.

검증: backend MaintenanceTests, Android 모델·입력 검증 단위 테스트, 앱/서버 빌드, lint, Pleos 에뮬레이터의 StartScreenAndroidTest(정비 노출·오너 등록·교체 완료·중복 요청) 통과. 실차 화면 치수는 별도 확인이 필요하다. 서버를 재시작해야 전체 목록·새 정렬이 반영된다.


## 기존 제조사 항목의 근거 누락 (2026-11-12)

개발 DB 조회에서 MANUFACTURER 항목 3개 모두 evidence_id가 없어 요약 API의 검증 필터에서 제외되는 것을 확인했다. 근거 ID가 없는 기존 항목은 해당 차량의 공용 목록에 반환하되 manufacturerEvidenceVerified=false와 riskLevel=UNKNOWN으로 구분한다. Android는 ‘제조사 근거 미확인’으로 표시하고 수정·최초 이력 등록을 제공하지 않는다. 검증된 권장 주기나 새 공식 근거로 승격하지 않는다. 근거가 지정됐으나 폐기됐거나 차량·항목·주기와 일치하지 않는 경우는 기존처럼 제외한다. 신규 MANUFACTURER 등록 시의 검증 요구는 유지한다. 기존 DB 데이터의 기준·값·차량 귀속은 변경하지 않았다.
