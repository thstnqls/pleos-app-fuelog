# 정비 목록과 사용자 등록 폼 (2026-11-12)

서버 `/maintenance/summary`는 검증된 제조사 기준(MANUFACTURER)을 먼저, 사용자 기준(USER)을 다음에 반환한다. 각 그룹은 위험(DANGER), 기한·거리 도래, 다음 예정일, 남은 거리, 항목명 순으로 정렬한다. 날짜와 거리를 임의 환산해 하나의 예상일로 만들지 않는다. 서버와 Android의 기존 2개 제한은 제거했다.

차량 정비 화면·홈·기본정보는 같은 정비 요약을 사용하며 제조사와 사용자 목록을 나눠 표시한다. 마지막 정비 날짜·거리가 모두 없는 항목은 오너에게 ‘첫 정비 기록 등록’을 제공한다. 사용자 항목이 없으면 새 사용자 정비 등록 버튼을 제공한다. 멤버와 미인증 사용자의 공용 목록 노출 및 오너만 수정하는 권한 검사는 유지한다.

등록 폼은 Material 윤곽선 입력칸, 항목/주기/마지막 정비 구역, 날짜 달력으로 구성한다. 주행 제한·화면 이탈 시 에디터와 달력을 함께 닫는다. 제조사 항목을 열면 이름·권장 주기는 읽기 전용으로 두고 기존 evidenceId와 MANUFACTURER basis를 보존한다. 사용자 등록은 USER로 저장한다. 검증되지 않은 제조사 문서를 새 제조사 근거로 생성하지 않는다.

검증: backend MaintenanceTests, Android 모델·입력 검증 단위 테스트, 앱/서버 빌드, lint, Pleos 에뮬레이터의 StartScreenAndroidTest(정비 노출·오너 등록·교체 완료·중복 요청) 통과. 실차 화면 치수는 별도 확인이 필요하다. 서버를 재시작해야 전체 목록·새 정렬이 반영된다.


## 기존 제조사 항목의 근거 누락 (2026-11-12)

개발 DB 조회에서 MANUFACTURER 항목 3개 모두 evidence_id가 없어 요약 API의 검증 필터에서 제외되는 것을 확인했다. 근거 ID가 없는 기존 항목은 해당 차량의 공용 목록에 반환하되 manufacturerEvidenceVerified=false와 riskLevel=UNKNOWN으로 구분한다. Android는 ‘제조사 근거 미확인’으로 표시하고 수정·최초 이력 등록을 제공하지 않는다. 검증된 권장 주기나 새 공식 근거로 승격하지 않는다. 근거가 지정됐으나 폐기됐거나 차량·항목·주기와 일치하지 않는 경우는 기존처럼 제외한다. 신규 MANUFACTURER 등록 시의 검증 요구는 유지한다. 기존 DB 데이터의 기준·값·차량 귀속은 변경하지 않았다.


## 제조사 근거 기본 목록에서 최초 정비 시작 (2026-11-14)

`GET /maintenance/summary`의 `manufacturerDefaults`는 `maintenance_manufacturer_evidence`의 미폐기 항목을 정비 계획 유무와 무관하게 반환한다. 항목별 문서·차종·연식·검증 상태와 현재 차량의 활성 계획 ID를 포함한다. Android는 ‘제조사 기본 정비 목록’을 먼저 표시하며 문서가 검증된 항목을 선택할 수 있다. 차종·연식 일치 검사는 아래 변경에 따라 생략한다.

오너가 항목을 선택해 시작일(첫 실제 정비 완료일)과 당시 누적거리를 입력하면 `POST /maintenance/manufacturer-defaults/{evidenceId}/start`를 호출한다. 본문은 `{confirmed:true,serviceDate:"YYYY-MM-DD",odometerKm:10000}`이며 `Idempotency-Key`가 필요하다. 거리 주기가 있으면 당시 누적거리도 필수다. 서버는 차량·오너·제조사 근거를 다시 검증하고 최초 계획 생성, 완료 이력 생성, 첫 회차 완료, 다음 계획 생성까지 하나의 트랜잭션으로 처리한다. 미래 날짜는 완료일로 저장하지 않는다.

동일 키·본문 재시도는 같은 완료와 다음 계획을 반환한다. 같은 근거로 이미 활성 계획이 있으면 중복 시작을 409로 거부한다. 입력·차량·권한 검증 실패 시 일부 계획이나 완료 이력을 남기지 않는다. 기존 완료 처리와 같은 event/completedPlan/nextPlan 계약이며 DB 마이그레이션은 추가하지 않는다.

요약의 `completedServices`는 차량 공용 완료 기록 최신 50건(이름·실제 완료일·당시 거리·다음 계획 ID)을 제공한다. 메모·비용·정비소 등 개인 상세는 포함하지 않는다. 다음 정비 카드는 D-day, 남은 거리와 진행 막대를 보여준다. 진행률은 날짜 주기와 유효한 최신 거리 주기 중 더 진행된 비율이며 0~100%로 표시한다. 기간이 없으면 D-day를 만들지 않고 거리만 표시한다.

검증: 정비 backend 테스트 23개, 앱 단위 테스트 및 빌드/lint. 기본 목록이 비어 있지 않아도 계획이 없을 수 있는 경우, 최초 완료·다음 회차 생성, 재시도·중복 시작, 잘못된 거리 입력 롤백, 차종 불일치·멤버 권한 거부, 진행률과 오래된 거리 제외를 검증했다. 실제 DB에는 검증된 근거 4건과 차량 프로필 2건이 있음을 읽기 전용 집계로 확인했으며 운영 데이터는 수정하지 않았다.


## 차종·연식 적용 검사 생략 (2026-11-14)

사용자 요청으로 제조사 기본 자료의 차량 제조사·모델·연식 일치 조건을 제거했다. 차량 프로필이 없거나 모델·연식이 달라도 검증된 미폐기 제조사 자료를 선택할 수 있다. 문서 검증 상태, HTTPS 출처·제목·범위, 항목명·주기 일치, 차량 오너 권한과 중복 시작 차단은 유지한다. 화면은 현재 차량의 권장 주기로 단정하지 않고 차종·연식 확인을 생략한다는 안내를 표시한다. 서버 재시작이 필요하다.
