# 차량 운행 목록과 N빵

2026-11-11 배포 서버 `http://sheetnews.ddns.net:3001/v3/api-docs`와
로컬 `fuelog-backend`의 `TripSummaryController`, `MobileInboxController`를 대조했다.

| 용도 | API | 인증 / 범위 |
|---|---|---|
| 운행 요약 저장 | `PUT /recording-intervals/{tripId}` | 설치 Bearer, 종료된 운행 원본 업로드 |
| 운행 요약 계산·조회 | `GET /recording-intervals/{tripId}/summary` | 설치 Bearer, 해당 운행 소유권 검사, 과거 후보 귀속 구간은 candidate 헤더 |
| 모바일 요약 목록 | `GET /mobile/inbox?cursor=0` | Supabase JWT, 모바일 확인함에 전달된 항목만, 운행 외 후보도 포함 |

차량 설치 인증으로 전체 운행 요약을 열람하는 목록 API는 없다. 모바일 JWT를
설치 비밀값으로 대체할 수 없으므로 차량 앱은 `home_recording.history`의 현재
인증 사용자 완료 운행을 최신 기록부터 표시한다. 충전 관측 전용 구간은 제외한다.
다른 단말 기록이나 로컬 저장소를 잃은 기록은 이 목록에 나타나지 않는다.

운행 탭 진입·새로 확인 시 기존 암호화 업로드 큐로 각 운행의 단건 요약을 조회한다.
로컬 ID를 서버 ID로 치환하고, 기존 종료·업로드·요약 작업 순서와 중복 요청 방지를
유지한다. 서버 요약이 도착하면 날짜·시각·소요 시간·거리·연비/전비·추정 금액에
사용한다. 응답 전에는 로컬 기록임을 표시한다. 유효하지 않은 값은 계산 불가로 표시한다.
기존에 저장된 전력비는 그대로 사용하며 새 단가나 결제금액을 임의로 생성하지 않는다.

N빵은 확인된 KRW 추정 금액에만 활성화된다. 1~99명을 선택할 수 있고 원 단위
반올림한 총액을 나눠 나머지 인원은 1원씩 더 부담하도록 안내한다.
사용자 변경·화면 이탈·주행 제한 시 계산 창을 닫는다. 결제·송금·정비비 합산은 하지 않는다.

전체 서버 이력이 필요하면 설치·차량·현재 사용자 소유권을 검사하는 차량용 목록 API가
추가되어야 한다. 현재 구현은 백엔드 테이블이나 API를 변경하지 않는다.
