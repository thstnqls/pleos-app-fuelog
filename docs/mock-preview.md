# 서버 연동 전 목업 미리보기

앱 프로세스 시작 시 서버 연결 응답을 검증하기 전까지 목업 화면을 기본으로 제공한다. 최초 화면은 C02 홈이며 C01 연결, C03 사용자 확인, C04 요약, C05 주유, C06 정비, C07 설정을 이동할 수 있다. 모든 화면에 목업 표시를 둔다. 목업 사용자 선택·기록 시작/종료·전달·해제·초기화는 UI 메모리 상태만 변경하며 실제 개인 인증이나 서버 변경 API에 연결하지 않는다. 화면 회전은 Bundle로 미리보기 상태를 유지한다. 실제 주행 제한은 적용된다.

기존 API_BASE_URL(local.properties 또는 Gradle 속성)을 설정하고 재빌드하면 앱 시작 시 연결 API를 확인한다. C07의 '설정된 서버 응답 확인'으로 재시도할 수 있다. URL 미설정, 네트워크 오류, HTTP 오류, 잘못된 JSON/상태/빈 요청 ID/잘못된 QR 유효기간이면 목업 유지. 유효한 connection/requests 응답을 파싱한 경우에만 실제 모드로 전환한다. WAITING이면 실제 QR 연결 화면, 등록 완료이면 실제 사용자 증명 화면으로 이동한다.

실제 모드로 전환한 후 다른 API 실패를 목업 성공으로 바꾸지 않는다. 개인 화면과 데이터는 기존 인증·권한 검사를 거친다. 목업 사용자와 기록을 실제 저장/업로드에 복사하지 않는다. 앱 프로세스 재시작 시 서버 응답을 다시 확인한다. 목업 UI는 별도 렌더링으로 제공하므로 실제 연동 UI와의 세부 문구/상태 차이는 있을 수 있다.
