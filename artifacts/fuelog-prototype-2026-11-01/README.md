# fuelog 공유용 화면 시안

공유본 작성일: 2026-11-01

## 파일 여는 방법

1. `fuelog-prototype.html`을 Chrome·Edge·Safari 같은 최신 데스크톱 브라우저로 엽니다. 별도 설치나 서버 실행은 필요하지 않습니다.
2. 상단 ‘차량 화면’·‘모바일 화면’에서 화면을 선택하거나, 시안 안의 메뉴·버튼을 눌러 이동합니다.
3. ‘차량 창 크기’와 ‘차량 상태’에서 좁은 창·주행 제한 상태를 확인할 수 있습니다.

이메일·메신저의 첨부파일 미리보기에서는 버튼이 동작하지 않을 수 있습니다. 파일을 내려받아 브라우저로 열어 주세요. 휴대폰 파일 미리보기 대신 PC 브라우저 사용을 권장합니다.

## 포함 파일

- `fuelog-prototype.html`: CSS와 화면 이동 JavaScript가 포함된 단일 HTML. 이 파일 하나만 전달해도 시안을 확인할 수 있습니다.
- `screen-requirements.md`: 페이지별 기능 요구사항·정책 검토·API 연결·수용 기준.
- `README.md`: 사용 안내.

화면별로 별도 HTML을 요청할 필요 없이, 하나의 파일 안에서 화면이 전환됩니다. HTML을 텍스트 편집기로 열면 화면 정의와 동작 코드를 확인할 수 있습니다.

## 확인해 볼 흐름

- 차량 홈 → 사용자 확인 / 운행 / 주유 / 정비 / 연결 설정
- 모바일 홈 → 주유 확인 → 실제 결제 금액 입력 → 확인 저장
- 모바일 운행 → 운행 상세 → 여행 정산 → 금액 입력 → 분담액 미리보기 → 공유
- 차계부 → 정비 기록 / 정비 예정
- 관리 → 차량 등록 / 사용자 연결 / 공유 범위

예시: 정산 금액 10,000원을 입력하면 3명에게 3,334원·3,333원·3,333원으로 배분됩니다.

## 시안의 범위

모든 값은 예시 데이터입니다. 실제 로그인·Bluetooth 연결·서버 저장·정산 전송·알림 발송은 수행하지 않습니다. 입력값은 체험용이며 새로고침하면 초기 예시로 돌아갈 수 있습니다. 실제 비밀번호나 개인정보를 입력하지 마세요.

이 공유본은 주요 화면 흐름을 확인하는 프로토타입입니다. 전체 기능 구현 및 실차 센서·주행 규제·차량 화면 크기 검증을 대신하지 않습니다.
